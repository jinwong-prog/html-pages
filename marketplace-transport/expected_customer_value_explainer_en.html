Expected Customer Value · 90d / 180d

What we cannot measure forever → what we measure instead → how one customer value is calculated

Why this model exists

The company already has an official LTV monthly view. It is useful — and it stays in place.

This model adds a clearer next step: look only at the next 90 days or 180 days, so we can later compare what we expected with real completed orders.

Expected Customer Value · 90d / 180d

Same structure: already earned + expected next. Different $ rule from company LTV. Fixed 90 / 180 days — easier to check.

1. How this compares with company LTV

Think of them as two related views, not rivals. Both care about platform money from a customer. The difference is how far ahead we look — and how easy that is to check. Also: company LTV uses GTV×10% + fee; this model uses driver_commission + premium_platform_support.

Simple takeaway Click to open or close

LTV = the company view you already know (GTV×10% + fee).

Expected Customer Value = past + next 90 or 180 days, using commission + platform fee fields on completed orders — easier to check later.

We are not throwing LTV away.

2. One customer value = two parts

Start with the final amount. Then show the two parts that create it.

How Expected Customer Value is calculated Click to open or close
  1. Look at completed orders (how many) and the platform money on each order (how much GoGoX earned — not full customer GTV).
    Table: order_master_table_hk. Per order: driver_commission + premium_platform_support. Not the same as company LTV (GTV×10% + fee).
  2. Split into two parts, then add:
    Already earned (past platform money)
    + Expected next (next 90 or 180 days)
    = Expected Customer Value · 90d / 180d

One line

Already earned + expected next = Expected Customer Value.

“Chance they book again” is only an estimate that they may book again in that period — not a promise of exactly N orders or a fixed profit.

4. How this value helps business decisions

The same customer value can guide different actions.

Important
This model does not replace the official monthly LTV table yet. Keep using company LTV as usual. Expected Customer Value is an extra 90 / 180-day view. It should only replace the old future method after a holdout test shows it predicts real customer orders and value more accurately.
