3. ROI Reality Check

短期財務回報偏弱——這不是適合用純 ROI justify 的 acquisition campaign；續做必須控成本、收窄 target。

ROI proxy 僅 5.97%（benefit proxy HK$15,094.5 ÷ 活動成本 HK$252,708）。此為粗略 proxy，不是 Finance 官方 ROI。

短期財務回報偏弱：ROI proxy 5.97%

活動真有增量：扣除對照組後 orders / GTV / platform_take 仍為正

活動不是只有「參加者 post 有收入」，而是扣除對照組後，訂單、GTV、platform_take 仍然有正增量。以下皆為人均（/ 人），不是 per order、也不是全體加總；pre / post 各 180 天（活動日 2025-11-14 至 11-16 不計）。

解讀：每人先算 pre 180 天與 post 180 天的差（Post−Pre），再比實驗組與對照組的平均變化差距（DiD）。+1.34 單/人 = 每人 post 期比 pre 期平均多完成 1.34 張單，不是「每張單」的增量。樣本：140 對 matched users。

6. 如果無做 Doggo Fest，結果會點？

用 matched control 作為「無活動代理」；將實際 post 180 日結果與 no-event counterfactual 比較。不是 forecast model。

Doggo Fest 的價值不是「post 有收入」，而是「實際 post 比無活動預期多了多少」——人均活動增量 +HK$25.37（140 對 matched users）。

活動後實際收入高於無活動預期，差距就是增量

若無做活動，根據相似用戶表現，這批人本來約會下跌；但實際參加者上升，中間差距可視為活動增量。

7. 2026 Campaign Playbook

如果要續做，關鍵不是「再辦一次」，而是換成更像精準 activation 的 campaign design。

面向 Recommendation Why KPI to Monitor Risk
Targeting 優先投放既有活躍寵物客與高意圖舊客 因果最強的 uplift 來自既有活躍客，而不是全體混合平均 Existing active platform_take uplift / 人 若 target 太闊，成本會重新稀釋回報
Offer design 改成分層 offer，不要所有人同一張券 避免把補貼浪費在本來就會下單的人身上 Offer redemption quality、post 30d repeat 券設計過複雜會降低使用率
Budget control 先縮活動成本，再談擴張 ROI proxy 只有 5.97%，Finance 會挑戰 Benefit proxy / event cost、cost per activated user 若維持大曝光成本，管理層很難批下一輪
Retention flow 新客首單後 30 天內加 follow-up flow 新客質量不差，但只看首單不足以回本 第 2 單率、第 3 單率、30d repeat 沒有 follow-up，活動價值會停在一次性體驗
KPI tracking 主看 platform_take uplift / 人；次看第 2、第 3 單率 比單看活動日流量或 ≥1 單留存更接近商業價值 Matched DiD、new user benchmark 若回到活動日 vanity KPI，決策會失焦
What not to do 不要用「純拉新 ROI 活動」做 headline 目前證據不支持這種說法 ROI proxy、incremental PT vs cost 會被 Finance 挑戰，亦會錯配 2026 目標

展開術語說明
ROI proxy 粗略回本率。用可觀察收益 proxy 除以活動成本，不是 Finance 官方 ROI。
DiD 差異中的差異。不是只看活動前後，而是看 treatment 比 control 多好多少。
platform_take 平台實際收入，本報告最核心 business KPI。
公式：driver_commission + premium_platform_support（平台向司機抽佣 ＋ 平台支援費；null 當 0，已對 BQ 驗證）。
注意：非 GTV、亦非 Finance 官方淨利（未扣營運成本）。
GTV 客戶支付總額，不等於平台賺到的錢。
Treatment 有參加活動、使用 Doggo Fest voucher 的用戶。
Control 沒參加活動，但活動前特徵相似的用戶。
Matched control 用來模擬「如果無做活動，本來會怎樣」的代理組。
Organic 同期自然來的非 Doggo 新客，只可用作 benchmark。
Uplift 相對於 no-event 代理多出來的增量。
CI 含 0 統計上不夠穩，不能講得太硬。
Benchmark 用來比較質量是否差太遠的參考組，不等於因果對照。
Retention flow 首單後的追單設計，例如 30 天內第二張券或訊息提醒。

9. Method Appendix

主報告先解決決策問題；這一節才放方法論，方便 Data / Finance / PM 補看。

主因果結論：140 對 matched users。新客 102 人無 pre window，不可作 DiD 主結論；只能用第 2、第 3 單率做 quality benchmark。
Treatment 定義
活動期 2025-11-14 至 2025-11-16 使用 Doggo Fest 相關 voucher 的完成單用戶，共 372 人。
Control 定義
Typical Pet 池中、活動前三項特徵相近的用戶，配對成 140 對 matched control。
Pre / Post window
Pre：2025-05-18 to 2025-11-13；Post：2025-11-17 to 2026-05-16；活動日不計入 pre / post。
Matching method
以 pre orders、pre GTV quartile、recency bucket 做 exact / bucket match；主輸出為 matched pairs。
項目 說明
DiD formula (Treatment Post−Pre) − (Control Post−Pre)
主 KPI completed_orders、GTV、platform_take；其中 platform_take 為主 headline。platform_take = driver_commission + premium_platform_support（COALESCE null→0；已對 BQ 驗證）
Direction split To venue 最高 +HK$66.00 / 人，但樣本較小，適合作輔助洞察，不宜壓過主故事
Sample limitation 232 人未配對；混合 DiD 不可直接乘以 372 全體 treatment
ROI caveat ROI proxy = matched 增量 + 新客 post platform_take，相對活動成本；不是 Finance 官方 ROI
Sanity check Event study pre-trend 大致平行；全池 control 同期下滑，支持「活動後表現並非市場普遍自然上升」
Event study：活動前平行趨勢（輔助可信度）

活動前兩組走勢大致相近，matched DiD 的平行趨勢假設有基本支持。
